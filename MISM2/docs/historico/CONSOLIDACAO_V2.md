# Escudo Feminino — Consolidação da V2

## Status

**V2 consolidada.**

A V2 mantém os algoritmos determinísticos como fonte de verdade e adiciona uma camada de raciocínio e linguagem natural para explicar os resultados.

## Entregas da V2

### Base analítica
- indicadores epidemiológicos;
- score epidemiológico;
- priorização;
- tendência estadual;
- detecção de anomalias;
- perfil epidemiológico;
- base de conhecimento.

### Raciocínio
- contexto geral raciocinado;
- contexto inteligente por intenção;
- contexto específico por câncer;
- separação entre dado observado, interpretação, impacto, recomendação e limitações.

### Linguagem natural
O chat reconhece e trata intenções como:
- situação geral;
- priorização;
- apoio à decisão;
- mortalidade;
- custo;
- permanência;
- faixa etária;
- tendência estadual;
- mudança temporal;
- anomalias;
- incidência;
- relatório executivo;
- câncer específico;
- vulnerabilidade.

### IA de linguagem
A IA atua como camada explicativa. O contexto produzido pelo Escudo é a fonte dos fatos apresentados à IA.

Regras principais:
- não inventar números ou fatos;
- não inventar diagnósticos;
- não transformar associação em causalidade;
- declarar insuficiência de dados quando necessário;
- preservar os valores fornecidos pelo sistema;
- separar observação, interpretação e recomendação.

### Validação
Foram testadas perguntas reais envolvendo:
- mudança temporal;
- apoio à decisão;
- priorização;
- mortalidade;
- anomalias;
- câncer específico.

### IA preditiva
O caminho técnico futuro foi documentado separadamente. Não há modelo preditivo implementado na V2.

## Fora do escopo da V2

- frontend definitivo;
- comparação entre municípios;
- expansão territorial;
- treinamento de modelo preditivo.

Esses itens ficam para a próxima evolução do projeto.

## Próxima evolução

A próxima etapa planejada é transformar o Escudo em uma plataforma de **análise comparativa territorial**, permitindo comparar Rio Claro com outros municípios e, posteriormente, comparar múltiplas cidades usando os mesmos indicadores.

## Marco

Esta documentação representa o fechamento funcional da V2. Alterações futuras devem preservar os componentes determinísticos já validados e ser feitas de forma incremental.
